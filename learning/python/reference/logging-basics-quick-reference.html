logging 基础速查

logging.basicConfig(...)：由应用入口统一设置最低级别、格式和输出位置。

logging.getLogger(__name__)：业务模块获取以当前模块命名的 logger；仅获取 logger 不等于记录日志。

DEBUG < INFO < WARNING < ERROR < CRITICAL。配置为 INFO 时，DEBUG 被过滤，INFO 及以上事件可被处理。

INFO 记录正常业务节点；WARNING 表示仍可继续但存在风险；ERROR 表示某项功能失败。在 except 中使用 logger.exception() 可记录 ERROR 和当前 traceback；它不负责重新抛出异常，显式 raise 才会继续传播。

业务日志应携带排查所需上下文，例如 table_name、limit、row_count；不要记录密码、API Key 或完整敏感数据。
