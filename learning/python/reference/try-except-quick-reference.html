try / except 精确捕获速查

try:
    result = operation()
    return result
except KnownError:
    return fallback

执行规则

情况结果
try 成功跳过 except
异常类型匹配跳过 try 剩余部分，执行对应 except
异常类型不匹配继续向调用方传播
多个 except 匹配只执行第一个匹配分支

当前配置场景

  • FileNotFoundError：路径对应的文件不存在。
  • json.JSONDecodeError：文件已读取，但 JSON 文本无法解析。

只捕获真正知道如何处理的异常。本章不使用裸 except: 或宽泛的 except Exception:，以免隐藏未知缺陷。

Debug 提问顺序

  1. try 中哪一步抛出了异常？
  2. 异常是否匹配某个 except？
  3. try 中哪些后续语句被跳过？
  4. 调用方最终拿到返回值，还是异常继续传播？
