Pydantic v2 BaseModel 速查

写法作用
class Input(BaseModel)声明一个运行时可验证的数据模型
Input.model_validate(data)从字典等外部数据解析并校验模型
Field(default=100, ge=0, le=1000)默认值与包含边界的数值约束
model.model_dump()把模型导出为普通字典
ValidationError必填字段缺失、转换失败或约束不满足时的异常

Pydantic v2 默认会对部分输入做解析，例如把 "20" 解析成整数 20；不要把这种转换和任意字符串清洗混为一谈。模型验证成功后，字段值才适合交给业务逻辑。
