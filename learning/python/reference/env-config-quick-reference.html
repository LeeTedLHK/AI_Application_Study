Day 18：配置读取速查

os.getenv(key, default) 读取进程环境变量；仅在键缺失时返回 default。环境值和 .env 文件值均是字符串；空字符串也算键已存在。

load_dotenv(path, override=False) 显式加载文件，只填充缺失的环境变量。此模式下：已有环境值 → 文件值 → getenv 默认值。

QueryInput.model_validate(data) 才处理类型转换和范围校验。只有 data 字典没有 limit 键时，模型才使用自己的默认 100；limit=None 或 "" 都是已提供的输入，会报 ValidationError。

.env 保存本地配置并被 Git 忽略；.env.example 可提交，但只写无密钥示例。当前项目的示例没有真实密钥。
