Context manager：进入与退出

__enter__(self) 的返回值交给 as 后的变量。

__exit__(self, exc_type, exc_value, traceback) 接收退出时的异常信息；无异常时后三项均为 None。

当 __enter__ 成功返回后，无论正常结束、return 还是块内异常，退出 with 都会调用 __exit__。进入本身失败时不调用。

__exit__ 返回 False 或 None 不压制块内异常，返回真值可以压制异常。资源清理必须由实现提供，with 不会猜测该关闭什么。
