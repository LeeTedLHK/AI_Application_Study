函数装饰器基础

Day 12 快速回忆：接收函数、返回 wrapper、保留结果。

一句话模型

@decorate 放在函数上方，核心上等价于 name = decorate(name)。

最小骨架

def decorate(func):
    def wrapper():
        # 调用前行为
        result = func()
        # 调用后行为
        return result

    return wrapper

名字分别指向什么

名字含义
func被包装的原函数对象
wrapper替代原函数名、增加额外行为的新函数
result原函数本次调用产生的返回值

执行时机

时机发生什么
执行到函数定义把原函数交给 decorator，并把返回的新函数绑定到原名字
调用被装饰函数执行 wrapper，再由 wrapper 调用原函数

排错顺序

  1. decorator 是否返回 wrapper？
  2. wrapper 是否真的调用 func？
  3. wrapper 是否把 result 返回给调用方？
  4. wrapper 的参数是否能传给原函数？
