Day 7：从文件读取

json.load(file) 从已打开的文件对象读取并解析；json.loads(json_text) 解析 JSON 字符串。路径字符串不是 JSON 内容。

with open(path, "r", encoding="utf-8") as file: 以 UTF-8 文本、只读方式打开文件；离开 with 缩进块自动关闭。读出的 Python 对象仍可使用，修改对象不会自动写回文件。

JSON 的 false 是布尔值；"false" 是字符串。解析器不会按字符串内容的含义把它转换为 bool。
