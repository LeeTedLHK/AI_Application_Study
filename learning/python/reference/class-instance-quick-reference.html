Python class 与实例

Day 10 最小对象模型速查：只覆盖 class、实例、__init__、self、属性和方法。

骨架

class QueryTask:
    def __init__(self, table_name, limit):
        self.table_name = table_name
        self.limit = limit

    def describe(self):
        return f"{self.table_name}:{self.limit}"

task = QueryTask("orders", 10)
result = task.describe()

读代码

写法含义
QueryTask(...)创建新实例；参数传给 __init__
self.name = name把右侧参数保存为当前实例的属性
task.name读取或修改该实例的属性
task.describe()调用实例方法；task 自动成为 self

选择提醒

临时、松散的 JSON 数据可以继续用字典。需要表达明确对象，并把状态和相关行为放在一起时，再考虑 class。

常见错误：漏写 self；只写 limit = limit 而没有保存到实例；在方法中写 limit 而不是 self.limit；误以为普通 class 会自动检查类型。
