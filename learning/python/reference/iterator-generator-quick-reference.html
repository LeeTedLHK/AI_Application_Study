Iterator 与 Generator

Day 11 快速回忆：逐项消费、暂停与恢复。

核心映射

写法发生什么
iterator = iter(values)从 iterable 得到记录位置的 iterator
next(iterator)取一个值并推进；耗尽后抛 StopIteration
for value in values自动获取 iterator、重复 next、处理 StopIteration
yield value产出值并暂停，下一次 next 从这里之后恢复

生成器骨架

def iter_values(values):
    for value in values:
        yield value

常见误区

调用生成器函数不会立即执行函数体；yield 不等于 return；生成器结束时的 StopIteration 通常由 for 自动处理；list 转成 iterator 不会删除 list 中的数据。
