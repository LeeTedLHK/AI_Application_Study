对象用于处理，JSON 文本用于交换

Python 对象 → json.dumps() → JSON 字符串
JSON 字符串 → json.loads() → Python 对象

Python 的 dict 不是 JSON 字符串。字符串外观像字典，也不代表内容是合法 JSON。JSON 是数据交换格式；本课用 Python 的 str 保存其文本。

最小例子

import json

payload = {"status": "paid", "active": True}
json_text = json.dumps(payload)
restored = json.loads(json_text)

print(isinstance(json_text, str))
print(restored["active"])

两个 print 都输出 Python 布尔值 True；而 json_text 内部的布尔字面量是 JSON 的 true。loads 的结果取决于 JSON 顶层内容，本课使用 JSON object，对应 Python dict。

三种容易混淆的值

Python 源码中的值类型与内容
{"ok": True}dict，不是 loads 所需的文本
'{"ok": true}'str，内容是合法 JSON
"{'ok': True}"str，但单引号 key 和 True 均不符合 JSON 语法

外层引号是 Python 字符串的界定符，不属于字符串内容；JSON 内容中的字段名和字符串必须使用双引号。
