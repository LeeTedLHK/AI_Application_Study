函数：把输入变成输出

参数接收输入 → 函数体处理 → return 交回结果

def calculate_fee(amount, rate=0.1):
    fee = amount * rate
    return fee

result = calculate_fee(200)
  • amount 是调用时必须提供的参数。
  • rate=0.1 有默认值，调用时可以省略。
  • return 把结果交给调用方，调用方可保存、判断或继续计算。

print 只负责显示；return 才是函数对外提供结果的方式。
