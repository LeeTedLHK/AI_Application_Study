Day 15 · 给容器标注元素类型

目标：让 SQL 查询结果、工具参数和 RAG 文档块的结构更容易被人、IDE 和静态检查工具理解。

def summarize_limits(limits: list[int]) -> dict[str, int]:
    return {"count": len(limits), "total": sum(limits)}

list[int] 表示元素期望是整数；dict[str, int] 表示键期望是字符串、值期望是整数。Python 3.9+ 可以直接使用内置容器的这种写法。

容器标注仍是约定，不会自动检查每一项，也不会把字符串转换成整数。运行时校验要由函数体或专门的模型完成。

今天先做阅读预测，再实现一个汇总函数。边界案例是空列表：结果应是 {"count": 0, "total": 0}。
