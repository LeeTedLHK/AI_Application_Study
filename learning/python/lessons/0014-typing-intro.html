Day 14 · 给函数写清输入与输出

目标：读懂 AI 应用函数的类型约定，区分标注与实际校验。

def table_label(name: str) -> str:
    return "table: " + name

print(table_label("orders"))

name: str 表示期望 name 是字符串；-> str 表示期望返回字符串。标注供人和类型检查工具理解接口，Python 本身不会因此自动检查或转换参数。实际操作仍可能因类型不合适而报错。

参数的 = 10 表示默认值，与类型标注用途不同。今天先掌握普通函数标注，不引入高级泛型。
