先会选，再会写：四种常用容器

容器是“把多个值组织在一起”的数据类型。选择时先问：需要顺序吗？会修改吗？按位置找，还是按名字找？

类型最核心的用途本项目中的例子
list有顺序、会增删的一串值聊天消息、检索结果
tuple有顺序、结构固定的一组值固定必填字段、坐标
set不重复、主要判断“是否属于”合法状态、权限集合
dict用 key 找对应 valueJSON、SQL 行、工具参数

最小例子

messages = ["用户提问", "助手回答"]
required_fields = ("department", "amount", "status")
valid_statuses = {"paid", "cancelled", "pending"}
row = {"department": "sales", "amount": 1200}

这些选择不是强制规则：用 list 也能保存合法状态。好的选择主要让代码表达意图，并减少不需要的操作。
