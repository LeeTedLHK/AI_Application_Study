Day 17 · 用 Pydantic 校验结构化输入

目标：把 API、Tool Calling 或 JSON 中的外部数据，转换成经过校验的 Python 对象，再交给业务逻辑。

from pydantic import BaseModel, Field

class QueryInput(BaseModel):
    table_name: str
    limit: int = Field(default=100, ge=0, le=1000)

query = QueryInput.model_validate({"table_name": "orders", "limit": "20"})
print(query.limit)       # 20，int
print(query.model_dump()) # {'table_name': 'orders', 'limit': 20}

BaseModel 根据字段标注定义数据模型；model_validate 接收外部字典并执行解析与校验。默认配置下，能安全解析的字符串数字可能被转换成整数；缺失必填字段、无法转换或违反约束时会抛出 ValidationError。

Field(default=100, ge=0, le=1000) 同时表达默认值和闭区间约束：0 与 1000 合法，-1 与 1001 不合法。model_dump() 把已验证模型转换回普通字典，适合后续序列化或交给业务层。

这和普通函数类型标注、dataclass 的区别是：Pydantic 的模型构造本身就是一个运行时输入边界。它仍然不是万能的业务规则引擎，跨字段规则需要额外设计。
