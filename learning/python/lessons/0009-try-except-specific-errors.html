Day 9：处理“预期之内”的失败

从读懂 traceback，前进到让后端对已知错误给出稳定结果。

本节唯一目标：使用一个 try 和精确的 except，只处理你明确知道如何应对的异常。

最小心智模型

try 中发生什么接下来发生什么
没有异常执行完 try，跳过所有 except
发生匹配的异常跳过 try 剩余语句，执行匹配的 except
发生不匹配的异常当前 except 不处理，异常继续向外传播

5～10 行最小例子

import json

def parse_config(text):
    try:
        return json.loads(text)
    except json.JSONDecodeError:
        return None

合法 JSON 会从 try 直接返回，except 不执行。非法 JSON 在 json.loads 处中断 try，转入匹配的处理分支。

关键边界：except json.JSONDecodeError 不会处理 FileNotFoundError。精确捕获可以避免把代码错误、权限错误等未知问题伪装成“JSON 格式错误”。

为什么 AI 应用需要它

配置文件、Prompt 模板、模型输出和 Tool 参数都可能出现可预期失败。调用方需要区分“文件不存在”和“内容非法”，才能选择补配置、修内容、重试或向客户端返回不同错误。把所有异常吞掉，只会失去真正的根因。

  2. 答案通过后，再完成 安全配置加载练习。
