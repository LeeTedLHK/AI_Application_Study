Week 1 · Day 5 · 一个核心概念

让 Python 文件既能复用，也能直接运行

一个 .py 文件就是一个模块。别的文件可以 import 它，并通过模块名访问其中的函数。

直接运行：__name__ == "__main__"
被导入：__name__ == 模块名
共同点：模块的顶层代码都会执行；入口保护中的代码只在直接运行时执行。

为什么需要入口保护

# query_tools.py
def build_config():
    return {"limit": 100}

if __name__ == "__main__":
    print(build_config())

直接运行 query_tools.py 时会打印演示结果；其他文件执行 import query_tools 时，只获得模块和函数，不会执行入口保护里的打印。

import 的最小用法

# app.py
import query_tools

config = query_tools.build_config()
print(config)

import query_tools 把模块名绑定到当前文件；用 query_tools.build_config 能清楚看出函数来自哪里。

AI 应用中的位置

FastAPI 路由会导入业务函数，测试会导入被测函数，Agent 会导入 Tool。若导入时自动运行演示、查询数据库或发起 API 请求，应用启动和测试就会产生意外副作用。
