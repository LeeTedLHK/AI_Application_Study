Week 1 · Day 4 · 一个核心概念

函数有自己的局部作用域

函数参数和函数内部创建的变量，默认属于本次函数调用。函数外部的模块变量不会因为内部出现同名局部变量而自动改变。

最小心智模型
参数也是局部变量；函数内赋值默认创建或更新局部名字；函数结束后，通过 return 把需要的结果交出去。

最小例子

status = "global"

def normalize_status(status):
    normalized = status.strip().lower()
    return normalized

result = normalize_status(" PAID ")

两个同名的 status 处于不同作用域。函数参数接收 " PAID "；函数外的 status 仍是 "global"。

为什么不应偷偷依赖全局业务状态

如果函数从外部可变变量中偷取筛选条件，调用者看函数签名无法知道完整输入，测试也会受执行顺序影响。在 FastAPI 或 Agent Tool 中，不同请求还可能互相污染。业务输入优先通过参数传入，结果通过 return 返回。

读取模块常量、导入的函数通常是正常做法；今天关注的是避免隐藏的、会变化的业务输入。
