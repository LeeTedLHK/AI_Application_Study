把磁盘里的配置读进程序

昨天处理的是 Python 字符串里的 JSON。今天将查询配置放在文件中，再读入程序。这是读取 AI 应用配置、工具参数样例与评测数据的基础；本节不存放密钥。

路径字符串 → open 打开文件 → json.load 读取并解析 → Python 对象

输入文件

day07_query_config.json 的内容如下。JSON 文件内容不是 Python 源码，不在整个对象外面再加一层字符串引号。

{
  "table_name": "orders",
  "limit": 20,
  "active": true
}

先读懂这几行

import json

path = "E:/Project/AI_Application_Study/learning/python/week01/data/day07_query_config.json"
with open(path, "r", encoding="utf-8") as file:
    config = json.load(file)

print(config["table_name"])
print(config["limit"])
  • path 是文件地址字符串，不是文件内容。本例使用你当前仓库的绝对路径，先不引入路径计算。
  • open(...) 打开文件并返回文件对象。"r" 表示只读；encoding="utf-8" 指定文本编码。
  • as file 把这个文件对象绑定到变量 file；它不是路径字符串。
  • with 管理文件的使用范围，离开缩进块时会自动关闭文件。此处只学习这一个用法，不展开上下文管理器实现。
  • json.load(file) 从已打开的文件读取并解析 JSON。本例顶层是 object，解析后得到字典；JSON 顶层不一定都是 object。

文件关闭后，已读入内存的 config 仍可使用。仅修改内存中的字典不会自动保存回文件；本小节不进行任何写入。

与昨天的区别

json.loads(json_text) 接收包含 JSON 的字符串；json.load(file) 接收可读取的文件对象。路径虽然也是 str，但路径文本不等于 JSON 内容。
