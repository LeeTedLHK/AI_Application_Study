Day 16 · 用 dataclass 和 enum 表达查询计划

目标：把 AI 工具的结构化输入表示成有名字、有默认值、可读的 Python 对象。

from dataclasses import dataclass
from enum import Enum

class QueryMode(Enum):
    PREVIEW = "preview"
    EXECUTE = "execute"

@dataclass
class QueryPlan:
    table_name: str
    limit: int = 100
    mode: QueryMode = QueryMode.PREVIEW

@dataclass 会根据带类型标注的字段生成常用的 __init__、__repr__ 和相等比较方法，减少只保存数据时的样板代码；它不会因为标注而自动校验类型。

Enum 用有限的命名成员表达状态或模式。plan.mode 是枚举成员，plan.mode.value 是可用于序列化的字符串。

没有默认值的字段必须写在有默认值的字段前面。今天先练查询计划，不引入 field(default_factory=...) 或冻结对象。
