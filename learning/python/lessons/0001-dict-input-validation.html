Day 2：先校验，再处理

SQL 查询行、API JSON 和 LLM 工具参数都来自函数边界之外。进入核心逻辑前先校验，能让失败更早、更清楚。

今天只记一个判断

data[key] 表示“这个 key 必须存在”；data.get(key) 或 key in data 表示“我要主动处理缺失”。

数据结构选择

tuple 表达固定、有顺序的必填字段；set 表达无重复、主要用于成员判断的合法值集合。
